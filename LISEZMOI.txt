QUIZ DES VOISINES
=================

Application web de quiz : l'admin crée des quiz dans un back office, les
joueurs y répondent depuis leur téléphone à une adresse du type
ton-compte.github.io/voisines.

- Site : Vue 3 + TypeScript + Vite, publié gratuitement sur GitHub Pages.
- Données, connexion admin, photos : Supabase (offre gratuite).
- Version : lot 1. Types de questions disponibles : texte libre, QCM,
  vrai ou faux, Qui suis-je ?, Quiz photo.


MISE EN ROUTE (une seule fois, environ 20 minutes)
==================================================

1. CRÉER LE PROJET SUPABASE
---------------------------

1) Sur https://supabase.com, crée un compte puis un projet (région
   conseillée : Paris ou Francfort). Note le mot de passe de la base.

2) Ouvre "SQL Editor", colle le contenu du fichier
   supabase/migrations/20261014000000_init.sql, puis clique "Run".

3) Ouvre "Authentication > Sign In / Providers" et désactive
   "Allow new users to sign up". Ton compte sera ainsi le seul possible.

4) Ouvre "Authentication > Users > Add user > Create new user".
   Saisis ton email et un mot de passe, et coche "Auto Confirm User".

5) Dans "SQL Editor", donne-toi les droits d'admin (remplace l'email) :

       insert into public.app_admins (user_id)
       select id from auth.users where email = 'ton@email.fr'
       on conflict do nothing;

6) Ouvre "Authentication > URL Configuration" :
   - Site URL      : https://ton-compte.github.io
   - Redirect URLs : ajoute https://ton-compte.github.io/admin
                     et http://localhost:5173/admin

7) Ouvre "Project Settings > API" et note :
   - l'URL du projet ;
   - la clé publique ("anon" ou "publishable").
   Ne copie jamais la clé "service_role" / "secret" dans le site.


2. CRÉER LE DÉPÔT GITHUB
------------------------

1) Crée un dépôt public nommé exactement ton-compte.github.io
   (remplace "ton-compte" par ton identifiant GitHub).

2) Envoie les fichiers du projet dans le dépôt avec GitHub Desktop
   (application gratuite, sans ligne de commande) :

   a. Décompresse quiz-des-voisines.zip : tu obtiens un dossier "quiz".
   b. Installe GitHub Desktop (https://desktop.github.com) et connecte-toi
      avec ton compte GitHub.
   c. File > Clone repository > choisis ton-compte.github.io > Clone.
      Un dossier vide ton-compte.github.io est créé sur ton ordinateur.
   d. Affiche les fichiers cachés :
      - Mac : dans le Finder, touches Cmd + Maj + . (point)
      - Windows : Explorateur > Affichage > Afficher > Éléments masqués
   e. Ouvre le dossier "quiz", sélectionne TOUT son contenu (y compris
      .github, .gitignore et .env.example) et copie-le dans le dossier
      ton-compte.github.io. Copie le contenu, pas le dossier "quiz"
      lui-même.
   f. Dans GitHub Desktop, la liste des fichiers ajoutés apparaît.
      En bas à gauche, écris "Quiz des voisines : MPC" dans Summary,
      clique "Commit to main", puis "Push origin" en haut.
   g. Vérifie sur github.com que le dépôt contient bien un dossier
      .github et un fichier package.json à la racine.

   Pour les mises à jour suivantes : remplace les fichiers dans le
   dossier, puis Commit et Push dans GitHub Desktop.

3) Dans le dépôt : "Settings > Pages > Build and deployment > Source",
   choisis "GitHub Actions".

4) "Settings > Secrets and variables > Actions > onglet Variables >
   New repository variable" : crée deux variables
   - SUPABASE_URL      = l'URL du projet Supabase
   - SUPABASE_ANON_KEY = la clé publique

5) Onglet "Actions" : relance "Publier sur GitHub Pages" si le premier
   passage a échoué faute de variables. Au bout de 2 minutes environ,
   le site répond sur https://ton-compte.github.io

   Remarque : si le dépôt porte un autre nom (par exemple "quiz"), ajoute
   une variable BASE_PATH = /quiz/ . Les adresses deviennent alors
   ton-compte.github.io/quiz/voisines


3. UTILISER L'APPLICATION
-------------------------

- Back office : https://ton-compte.github.io/admin
- Un quiz     : https://ton-compte.github.io/<adresse-choisie>


TRAVAILLER SUR LE CODE
======================

Commandes à lancer dans le dossier du projet :

    npm install
    cp .env.example .env.local   (puis renseigne les deux valeurs)
    npm run dev                  (site local sur http://localhost:5173)
    npm test                     (tests de la notation)
    npm run build                (version de production dans dist/)


ORGANISATION DES FICHIERS
=========================

src/player/                 écrans joueur : choix du joueur, question,
                            correction, résultat
src/admin/                  back office : connexion, liste des quiz,
                            fiche quiz, éditeur de question
src/scoring.ts              calcul des points (testé dans scoring.test.ts)
src/types.ts                types de questions et de réponses
supabase/migrations/        tables, règles d'accès, fonctions get_quiz
                            et save_question
.github/workflows/          publication sur GitHub Pages, réveil
                            hebdomadaire de Supabase
scripts/spa-fallback.mjs    copie index.html en 404.html pour que les
                            adresses du type /voisines fonctionnent


RÈGLES DE NOTATION (points sur 1 par question)
==============================================

Texte libre           1 si le joueur indique "J'avais juste", sinon 0
QCM                   1 si les cases cochées sont exactement les bonnes,
                      sinon 0
Vrai ou faux          1 ou 0
Association (lot 1)   paires justes / nombre de paires
Chronologie (lot 1)   éléments bien placés / nombre d'éléments


LIMITES CONNUES
===============

- Les bonnes réponses sont envoyées au navigateur pour la correction :
  un joueur averti peut les lire avec les outils de développement.
- Un projet Supabase gratuit se met en pause après 7 jours sans
  activité. Le workflow "Garder Supabase actif" l'appelle deux fois
  par semaine.
- Les adresses de quiz sont servies par 404.html : le jeu fonctionne
  normalement, mais l'aperçu du lien dans WhatsApp peut être sommaire.
